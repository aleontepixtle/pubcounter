Security
How we protect your credentials:
  • Encryption at Rest: All credentials are encrypted using AES-256 before being stored in the database.
  • Encryption in Transit: All communication is encrypted via HTTPS through Cloudflare Tunnel.
  • Minimal Exposure: Credentials are only decrypted temporarily when running automation jobs.
  • Automatic Cleanup: Temporary credential files are immediately deleted after use.
Help
Where to find your TOTP secret:

When you set up 2FA for JW.org, you were given a secret key (usually a long string of letters and numbers). This is different from the 6-digit code you enter when logging in.

If you don't have this key, you may need to reset your 2FA in JW.org settings.
